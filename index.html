Flujo del proceso

1. Importación
El analista sube el Excel base y se cargan todos los funcionarios.
2. Cálculo
Se revisa la planilla importada y se corrigen casos puntuales desde la página.
3. Validación técnica
Jefe de Departamento valida o devuelve al analista.
4. Aprobación final
Jefe de División aprueba o rechaza la carga.

2. Datos del proceso y acciones

El cálculo base se mantiene según la planilla Excel importada. En esta sección solo se identifica formalmente la planilla antes de enviarla a validación. El año se toma automáticamente del sistema para evitar duplicidad de datos en el reporte financiero.

Importante: la página no reemplaza masivamente los días hábiles ni el monto diario del Excel. Si un funcionario requiere corrección, usa Modificar; el total a cargar y los totales generales se recalculan inmediatamente.

Trabajo de información para carga Edenred

Una vez aprobada una planilla por Jefe División, cargue aquí el Excel base entregado por Edenred. El sistema completará automáticamente la columna de monto por RUN/RUT, eliminará a quienes queden sin monto y descargará un nuevo archivo con la misma estructura de columnas del formato original.

Se descargarán dos archivos: 1) Excel de carga Edenred con los registros encontrados y monto asignado; 2) Excel de no encontrados para identificar funcionarios aprobados que no aparecen en la plantilla Edenred.
